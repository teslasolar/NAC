Core Components

ArcGIS Enterprise consists of four core components that together form a complete geospatial platform:

Portal

Web interface for accessing, sharing, and managing maps, apps, and data across the organization

Server

GIS server for publishing and hosting map services, geoprocessing tools, and imagery

Data Store

Data management component for relational, tile cache, and spatiotemporal big data

Web Adaptor

Integrates with existing web servers for security, load balancing, and reverse proxy

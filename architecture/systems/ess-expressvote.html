Security Features

Encryption & Digital Signatures

Election programming and vote data are encrypted and digitally signed to verify authenticity and prevent tampering.

Secure Boot

System uses Secure Boot and application allowlisting to verify only certified OS, software, and firmware are running.

Self-Diagnostic Tests

At startup, the unit performs comprehensive diagnostic tests to verify internal functionality and alerts users of any errors.

Detailed Audit Logs

Each unit generates detailed audit logs of all actions and events. Vote data is digitally signed as committed to memory.

Tamper-Evident Design

Physical security features with tamper-evident seals and locked access to internal components.

Air-Gapped Operation

Machines operate without any network connection, preventing remote attacks and ensuring vote integrity.

Paper Ballot Record

Voter-Verifiable Paper Audit Trail (VVPAT)

  • ✓ Thermal summary card printed for each vote
  • ✓ Clear window allows voter to review printed choices
  • ✓ Paper record secured inside attached module
  • ✓ Human-readable text + machine-readable barcodes
  • ✓ System scans barcode to verify no printing errors
  • ✓ "No selection" printed for skipped contests
  • ✓ Paper record not directly accessible to voters

Known Concerns

⚠ Physical Access Vulnerability

Security researchers have identified that physical access to voting machines could potentially allow tampering. Mitigation: Strict chain of custody, tamper-evident seals, and poll worker oversight.

⚠ Supply Chain Concerns

As with all electronic voting systems, supply chain security is a concern. Mitigation: Vendor certification, component verification, and pre-election testing.

⚠ 2024 Cambria County Issue

During 2024 elections, ES&S machines in Cambria County had ballot scanning issues due to a "ballot printing error", causing voter confusion and long lines. This was a localized incident addressed by poll workers.

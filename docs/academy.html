Glossary

Row Officer
Independently elected county official (Controller, Treasurer, etc.)
ACFR
Annual Comprehensive Financial Report - the county's audited financials
Mill
$1 of tax per $1,000 of assessed property value
Home Rule
County governs itself via charter, not state code

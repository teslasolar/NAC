Contract Considerations

Voting Machine Contract
10-year contract signed 2019. Concerns raised about vote-switching issues in 2023 and long wait times in 2024. County certified results despite documented anomalies.
Court System Dependency
CountySuite provides critical e-filing services. Single vendor dependency for court operations. Part of PA AOPC approved vendor list.
GIS Platform
ESRI is industry standard for government GIS. High switching costs but reliable platform. Integrates with assessment and planning functions.

Known Infrastructure Issues & Audit Findings

CRITICAL

ES&S ExpressVote XL - Vote Display Anomalies

Date: November 7, 2023 | Status: Certified despite concerns

Voters reported selecting one candidate but seeing a different candidate displayed on the ballot summary screen. Multiple documented instances. County certified results. 150+ L&A testing documents missing.

CRITICAL

Voting System - Excessive Wait Times

Date: November 2024 | Status: Under review

Some polling locations experienced 6+ hour wait times. System throughput issues. Possible machine allocation problems or technical difficulties.

HIGH

MDJ Court System - Warrant Procedure Documentation

Courts: MDJ 03-3-02, MDJ 03-2-11 | Status: Recurring finding

Controller audits found inadequate arrest warrant procedures and documentation failures. System controls may not be enforcing proper workflow. Recurring issue across multiple audit cycles.

MEDIUM

L&A Testing Documentation Gap

System: Election Management | Status: Pending review

150+ Logic and Accuracy testing documents reported missing or incomplete. Documentation system may have gaps in retention or tracking capabilities.

Recommendations

Independent Voting System Audit
Commission third-party security audit of ES&S ExpressVote XL systems, including source code review and penetration testing.
Document Management System
Implement centralized document management with mandatory retention policies for election-related materials per 25 P.S. requirements.
Court Workflow Automation
Review CountySuite configuration for MDJ courts to enforce warrant procedure compliance and generate audit trails.
Disaster Recovery Testing
Conduct annual DR testing with documented results. Ensure critical systems have tested failover capabilities.

queries/ - Markdown SQL Queries

Self-documenting queries for the NAC database

Home Source Docs Candidate
Usage:

npm run nac query <filename>

Example: npm run nac query statutory-requirements.md

Available Queries

statutory-requirements.md

Get all Controller-related statutory requirements - duties, board memberships, and Article XVI sections.

npm run nac query statutory-requirements.md

controller-case.md

The statutory case for Controller candidacy - maps qualifications to PA Code requirements.

npm run nac query controller-case.md

annual-audit-plan.md

Generate annual audit plan by officer and audit area.

npm run nac query annual-audit-plan.md

coverage-gaps.md

Find PA Code sections not yet fully implemented.

npm run nac query coverage-gaps.md

officer-detail.md

Get detailed audit areas for a specific row officer.

npm run nac query officer-detail.md officer=sheriff

Built-in Commands

coverage

PA Code coverage by article

npm run nac coverage

officers

All row officers and audit areas

npm run nac officers

modules

ISA-95 modules by level

npm run nac modules

duties

Controller statutory duties

npm run nac duties

stats

Database statistics

npm run nac stats

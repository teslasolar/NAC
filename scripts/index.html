Scripts

nac-cli.js CLI

Command-line interface for querying the NAC SQLite database. Supports built-in queries and markdown-driven custom queries.

npm run nac [command] [args...]

init-db.js Database

Initializes the SQLite database from PA Code coverage JSON. Creates tables for articles, sections, modules, row officers, audit areas, board memberships, and statutory duties.

npm run init-db

build.js Build

Build script v2.0 - generates manifest.json from ISA-95 modules and PA Code coverage data.

npm run build

generate-module.js Generator

Module generator - creates new ISA-95 compliant modules from templates with proper structure and documentation.

node scripts/generate-module.js [level] [name]

Overview

The NAC API provides a data integration layer for accessing Northampton County budget data, row officer information, and links to official county systems.

Quick Start (Browser)

<script src="src/api/nac-api.browser.js"></script>
<script>
  // Access budget data
  console.log(NAC.budget.total); // 582000000

  // Format currency
  console.log(NAC.formatCurrency(NAC.budget.total)); // $582,000,000

  // Get row officer data
  const treasurer = NAC.getRowOfficer('treasurer');
  console.log(treasurer.revenue); // 118000000

  // Open county page
  NAC.openCountyPage('controller');
</script>

API Endpoints

GET /api/budget
Returns FY2024 budget summary with categories
GET /api/budget/history
Returns budget history 2021-2026
GET /api/officers
Returns all 8 row officers with budgets and revenues
GET /api/officers/:id
Returns specific row officer by ID (e.g., treasurer, sheriff)
GET /api/revenue
Returns revenue sources breakdown
GET /api/debt
Returns county debt status and capacity
GET /api/gracedale
Returns Gracedale nursing home metrics
GET /api/metrics
Returns controller metrics (per capita, claims volume)
GET /api/links/county
Returns norcopa.gov links for all departments

Usage Example (Node.js)

const { DataService, NACClient } = require('./src/api');

// Get budget summary
const data = new DataService();
console.log(data.getBudgetSummary());
// { fiscalYear: 2024, total: 582000000, ... }

// Get county endpoints
const client = new NACClient();
console.log(client.getRowOfficerEndpoints());
// { controller: 'https://www.norcopa.gov/...', ... }

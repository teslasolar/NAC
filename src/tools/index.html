Detection & Analysis Tools

🔍 Duplicate Detector

§1730 Pre-Audit Claims

AI/ML pattern matching to identify duplicate or suspicious payments before they're issued.

  • Levenshtein string similarity for vendor matching
  • Configurable similarity threshold (default 85%)
  • Invoice number and amount matching
  • Detailed flagging report generation
DuplicateDetector.js

📊 Budget Dashboard

§1705 Fiscal Supervision

Real-time budget monitoring with variance detection and projected year-end analysis.

  • Spending rate analysis (annualized)
  • Threshold alerts (80% warning, 95% critical)
  • Projected overrun detection
  • HTML dashboard generation
BudgetDashboard.js

📋 Contract Analyzer

§1730 Pre-Audit

Analyze contracts >$100K against industry benchmarks and competitive bidding requirements.

  • Industry benchmark comparison (IT, legal, construction, etc.)
  • Competitive bid verification
  • Renewal tracking and expiration alerts
  • Potential savings identification
ContractAnalyzer.js

Audit & Compliance Tools

📁 Audit Workpapers

§1720 Audit & Settlement

GAGAS-compliant audit documentation system for row officer audits.

  • Standardized workpaper templates
  • Finding documentation (condition, criteria, cause, effect)
  • Test result tracking with exception rates
  • Pre-built procedures for all 8 row officers
AuditWorkpapers.js

✅ Claims Processor

§1730 / §1731

Pre-audit claims workflow with automated checks and approval routing.

  • Automated validation checks (6 standard checks)
  • Tiered approval thresholds ($5K/$25K/$100K)
  • Auto-approval for low-risk claims
  • Warrant issuance per §1731
ClaimsProcessor.js

Quick Start

const tools = require('./src/tools');

// Detect duplicate payments
const detector = tools.createDuplicateDetector({ threshold: 0.85 });
const results = detector.scan(payments);
console.log(detector.generateReport(results));

// Monitor budget variances
const dashboard = tools.createBudgetDashboard(budgetData);
const analysis = dashboard.analyze(departments);
const html = dashboard.generateHTML(analysis);

// Start a row officer audit
const audit = tools.createAudit({
  entity: 'Treasurer',
  period: '2025',
  auditor: 'T. Frumkin'
});
const procedures = tools.AuditWorkpapers.getRowOfficerProcedures('treasurer');

// Process claims
const processor = tools.createClaimsProcessor();
const claim = processor.submitClaim({
  vendor: 'ACME Corp',
  amount: 15000,
  department: 'Public Works',
  accountCode: '100-4100-001',
  invoiceNumber: 'INV-2026-001',
  invoiceDate: '2026-01-15'
});
